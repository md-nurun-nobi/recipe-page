# Recipe Page

A responsive recipe page built with HTML and Tailwind CSS.

## Overview

This project is a solution to the Recipe Page challenge from Frontend Mentor. The goal was to build a responsive recipe page that matches the provided design as closely as possible.

## Built With

- HTML5
- Tailwind CSS
- Vite
- Responsive Design

## Features

- Responsive layout
- Mobile-first design
- Desktop layout
- Custom colors
- Google Fonts
- Semantic HTML
- Styled lists and table
